## SR Inqly 2.1.1

Improved neon drawing, temporary trails and toolbar controls.

### Improvements and fixes

- Smoother neon curves and softer glow, with the same geometry maintained during fading.
- Gentler 1.8-second fade in drawing order after the configurable 1–15-second hold.
- Large minus/plus controls for fade delay instead of tiny spin-box arrows.
- Desktop neon uses the updated pen width for each new stroke.
- Direct Neon and Desktop neon switches in the compact toolbar.
- Pen/neon width options in the compact color dropdown.

Windows 10/11, 64-bit. Python is not required for the installer or portable build.

Desktop neon is opt-in and session-only. Underlying clicks and drags still activate Windows applications. Turn off Neon or Desktop neon to stop it. Temporary trails are not recoverable with Redo. The installer is not digitally signed.

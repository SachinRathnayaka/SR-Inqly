# SR Inqly 2.0.4

Write, draw, highlight and annotate over your Windows desktop with a floating workspace.

## In this version

- Fix stale text appearing at old positions after editing or moving a text box.
- Keep click-to-toggle desktop mode and clear inactive tool highlights.
- Preserve customizable crosshairs, independent marker settings, full/compact toolbar layouts and light/dark/custom themes.
- Fetcher provides non-destructive crop restoration, move, resize, rotation, flip, clipboard copy, duplication and layer controls.
- Source is organized into application, tests, scripts, packaging and documentation folders, with current interface screenshots.

## Downloads

- **Installer:** `SR Inqly Setup 2.0.4.exe`.
- **Portable:** `SR-Inqly-2.0.4-Windows-Portable.zip` — extract the full archive and open `SR Inqly.exe`.
- **Source:** `SR-Inqly-2.0.4-Source.zip`.
- **Integrity:** `SHA256SUMS-2.0.4.txt`.

Windows 10/11; Python is bundled in the installer/portable app. Binaries are currently unsigned. Press **Esc** to return to desktop mode; **Ctrl+Alt+Q** provides emergency exit.

## Verification and limits

Document, cache pixel equality, stale-text, cache eviction and native interaction checks accompany the source. Local verification is summarized in `docs/repository-verification.md`. Physical mixed-DPI multi-monitor hotplug, dual 4K, 120/144 Hz, pressure-aware stylus rendering and a 30–60 minute soak remain unverified or unsupported as documented in the README.

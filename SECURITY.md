# Security reporting

Do not include passwords, signing certificates, private keys or private desktop screenshots in public issues.

For a suspected security vulnerability, use GitHub's **Report a vulnerability** option if private vulnerability reporting is enabled for this repository. Otherwise contact Sachin Rathnayaka through the [official developer profile](https://github.com/SachinRathnayaka) to arrange a private report before disclosing sensitive details publicly.

Release binaries are currently unsigned. SHA-256 checksums are included with prepared releases. The custom application license does not replace the licenses of bundled third-party components.

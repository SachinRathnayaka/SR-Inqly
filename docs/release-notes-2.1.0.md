# SR Inqly 2.1.0

## New

- Neon pen glow in your selected color.
- Temporary pen trails: configurable 1–15 second hold, followed by smooth fading from the start of the drawn path.
- Desktop neon: optional fading mouse trails while underlying desktop clicks and drags continue normally.
- Full and compact toolbar controls with saved pen effect preferences.

## Downloads

- `SR.Inqly.Setup.2.1.0.exe`: Windows installer.
- `SR-Inqly-2.1.0-Windows-Portable.zip`: extract everything, then launch `SR Inqly.exe`.
- `SR-Inqly-2.1.0-Source.zip`: organized application source.
- `SHA256SUMS-2.1.0.txt`: file integrity checksums.

Windows 10/11 64-bit. Python is not required for packaged builds. The installer remains unsigned. Source Available and third-party license notices remain included.

Desktop neon passes clicks through to underlying apps; it is intentionally opt-in each session. Temporary trails are excluded from document selection and Redo. See [Pen effects](pen-effects.md) for behavior and limits.
